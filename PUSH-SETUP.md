# Push-уведомления чата клана (как WhatsApp)

Сайт: **https://leveluptracker.web.app/**

## Как работает

1. Кто-то пишет в **Кланы → Сообщения**.
2. Сообщение сохраняется в Firebase.
3. Push уходит на телефоны остальных участников — **даже если приложение закрыто или давно не открывали**.

### Два режима

| Режим | Когда работает | Что нужно |
|-------|----------------|-----------|
| **Бесплатный** | Отправитель **онлайн** в момент отправки | Expo push-токен у получателей |
| **Серверный (WhatsApp)** | Push **всегда**, отправитель может сразу закрыть приложение | Firebase **Blaze** + Cloud Function |

## Настройка (один раз каждому пользователю)

1. Откройте https://leveluptracker.web.app/
2. **Войдите по email**
3. **Кланы** → вступите в клан
4. **Сообщения** → **«Включить уведомления»** → **Разрешить**
5. **iPhone:** «Поделиться» → **На экран Домой**, открывайте только с иконки

## Проверка

1. Два аккаунта в **одном** клане
2. У **обоих** включены уведомления
3. Второй **закрывает** браузер / сворачивает приложение
4. Первый пишет в **Сообщения**
5. У второго — уведомление на экране

## Серверный push (полный WhatsApp-режим)

Cloud Function `onClanMessageCreated` шлёт push **с сервера** при каждом новом сообщении (FCM + Expo).

1. В [Firebase Console](https://console.firebase.google.com/project/levelup-ff95c/usage/details) включите **Blaze** (обычно $0 при малой нагрузке)
2. Деплой функций:

```powershell
cd tracker-mobile
npx firebase deploy --only functions:onClanMessageCreated --project levelup-ff95c
```

3. Синхронизация токенов участников (один раз):

```powershell
node scripts/sync-clan-push-tokens.cjs
```

## Деплой сайта

```powershell
npm run deploy:hosting
```

## Если push не приходит

- Снова нажмите **«Включить уведомления»** в Кланах
- iPhone: только через иконку PWA на рабочем столе
- Chrome: замок у адреса → Уведомления → Разрешить
- Для FCM-токенов без Blaze: включите Cloud Function (см. выше)
