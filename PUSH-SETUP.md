# Push-уведомления чата (бесплатно, без Blaze)

**Платный тариф Firebase не нужен.** Используются бесплатные сервисы:

- **Firebase Spark** — чат и хранение сообщений (бесплатно)
- **Expo Push** — доставка уведомлений на телефон (бесплатно)

## Как это работает

1. Вы пишете сообщение в чате клана.
2. Сообщение сохраняется в Firebase.
3. Ваш телефон **бесплатно** отправляет push остальным участникам через Expo.
4. У них приложение может быть **закрыто** — уведомление всё равно придёт на экран (если они один раз включили уведомления).

Это тот же принцип, что у многих бесплатных приложений: сервер Google за push не платите. 

## Что нужно сделать (один раз, каждому)

1. Откройте https://tracker-mobile.expo.app/
2. **Войдите по email** (не локальный аккаунт).
3. **Кланы** → вступите в один клан с другом.
4. Вкладка **«Сообщения»**.
5. **«Включить уведомления»** → **Разрешить**.
6. **iPhone:** «Поделиться» → **На экран Домой**, открывайте только с иконки на рабочем столе.

## Проверка

| Шаг | Действие |
|-----|----------|
| 1 | Два аккаунта в **одном** клане |
| 2 | У **обоих** включены уведомления |
| 3 | Второй **закрывает** сайт / сворачивает браузер |
| 4 | Первый пишет в **Сообщения** и жмёт отправить |
| 5 | У второго — уведомление на телефоне |

```powershell
## Деплой на tracker-mobile.expo.app

Если `read ECONNRESET` при `npm run deploy:web`:

1. **Сначала:** `npm run deploy:expo` (загрузка через curl, не node-fetch)
2. **Сеть:** отключить VPN, попробовать мобильный интернет, PowerShell вне Cursor
3. **GitHub Actions:** см. `.github/workflows/deploy-expo.yml` — секрет `EXPO_TOKEN`, Run workflow
```

## Ограничение бесплатного режима

Push уходит **в момент отправки**. Тот, кто **пишет**, должен быть онлайн (открыт сайт или вкладка).  
Если никто не отправляет сообщение — push некому слать (это нормально для бесплатной схемы).

Сообщения в чате **всегда сохраняются** в облаке: получатель увидит их, когда откроет приложение, даже без push.

## Blaze / Cloud Functions

**Не обязательны.** Нужны только если захотите платный серверный push без участия телефона отправителя. Для чата клана бесплатного режима достаточно.
